# Nova UI v0.1.0 - Initial Open-Source Release

Initial public release of the Nova UI cross-framework design system and Angular component suite.

### Packages Released
- `@nova-ui/tokens`: Design tokens for color palettes, spacing, typography, elevation, shadows, radius, and responsive breakpoints.
- `@nova-ui/styles`: Modern CSS architecture leveraging `@layer nova.reset, nova.tokens, nova.components, nova.utilities`, zero-runtime CSS variables, and light/dark theme presets.
- `@nova-ui/core`: Framework-agnostic contracts, TypeScript interfaces, and accessibility utilities.
- `@nova-ui/angular`: 16 production-ready Angular standalone components:
  - **Foundations**: Button, Input, Card, Badge, Alert
  - **Form Controls**: Textarea, Select, Checkbox, Radio, Switch (with full `ControlValueAccessor` / Reactive Forms support)
  - **Overlays & Navigation**: Modal Dialog, Dropdown Menu, Tooltip, Tabs
  - **Feedback**: Loading Spinner, Shimmer Skeleton
